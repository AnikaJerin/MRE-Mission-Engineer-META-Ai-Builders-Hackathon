# T12 v1: six development and six source-grounded evaluation cases

Frozen before owner execution. Six existing readiness/contract cases are the development
set. Six NEW source-assessment tasks use three separate publication families: early
MIT/KSC scale-up, computational anode screening, and MAIT plant modeling. No source
family crosses development/evaluation; paired evaluation tasks within each family
are dependent. Twelve cases do NOT mean twelve independent reactor experiments.
Development and evaluation test different aspects; never pool their accuracy.

This is a scoped protocol amendment: six bounded evaluation tasks, not six new full
reactor investigations or a prospective field study. Public references were inspected
by the developer to author cases/labels. They are withheld from model prompts, not
unknown to the developer or guaranteed absent from pretraining. Existing pilots and
engineering investigations remain development evidence, unchanged.

Each case: model-selected source receipt or arithmetic check, initial answer, critic,
revision, two fresh drafts and selection. Seven unique requests; initial/critic/revision
branch uses four, control uses the shared selection plus three independent drafts/
selection calls. Thus equal-call branches share the chosen local evidence. The critic
is the same model, not independent expert review. All model outputs use native
function submissions, validated locally, with no arbitrary code execution or retries.
Per case max reservation $1.75; six cases $10.50, both splits $21.00. These are local
reservations, not provider caps. Costs and failed attempts remain visible.

Ground truth: source-specific labels and required citations, exact missing-record
sets for constructed/readiness cases, independent numerical references with explicit
units/tolerances. Source records are short factual paraphrases of NTRS abstracts;
no protected PDFs/figures redistributed. Numeric checks compare production float
implementation and independent Decimal/Fraction implementation before paid work.
31.998 g/mol O2 is a declared approximation; Faraday reference uses exact SI e*NA.
An 8760-hour year is a stated 365-day design convention. Neither ideal oxygen nor a
rate derived from an annual target is an experimentally measured yield/rate.

Metrics: correct verdict/count per split, exact missing-record set, citation coverage,
numeric accuracy with units; unsupported endorsements, missed/false contradictions,
paired corrections/regressions; valid/failed/not-attempted counts. Report denominators,
case-level rows and source-family grouping. Null denominator is not 100%. Arithmetic
without numeric task must be null with unit not_applicable. Known citations do not
validate every free-text sentence. Rationale and next-evidence usefulness/optimality
are NOT independently scored. Reference labels are not reactor-fault ground truth.
Checklist reads typed record fields without reading the answer key; it is a strong
baseline and may equal/outperform Meta. Preserve equal/negative outcomes.

Freeze includes suite data, key, this protocol and relevant reasoning/physics/parser/
transport code. UI/export code is outside the scientific freeze. Evaluation batch
requires a complete six-case development batch under the same freeze. The first
start of an evaluation batch is recorded separately even if a request later fails.
A new code freeze after evaluation exposure is a development rerun, not a fresh blind
holdout. Any attempt history is displayed; no cherry-picking a successful run name.

T12 execution complete only after six development and six evaluation case workflows
finish under one freeze and live-api mode. Completing execution does not imply all
answers pass, or that general engineering value is established. UI shows pending
until actual owner-run reports exist. The assistant must not execute tests/API.
