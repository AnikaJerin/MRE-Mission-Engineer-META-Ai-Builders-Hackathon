Ground truth is versioned reference labels for the twelve explicitly supplied
constructed claims, plus numerical references from a separate Decimal/Fraction
implementation. Each label includes source-block requirements and a written basis.
Some labels concern what the publication reports, not an independently observed
physical mechanism. Not-established labels identify missing premises; they are not
proof a hypothesis is false. Porosity-method ambiguity is retained, not silently
resolved by the evaluator. Atomic percentage and weight percentage are different
bases; no unvalidated conversion is supplied.

No independent global fault taxonomy, calibrated probability or uniquely best next
experiment is available from these packets. The report therefore scores only the
explicit ledger and numeric fields; no LLM judges its own prose. Required citation
coverage validates reference selection, not entailment of every sentence. The next
evidence request and unconfirmed hypotheses remain inspectable and unscored.

Provenance: every supplied source block has URL and exact section/table location;
all facts are factual transcriptions/paraphrases. Raw measurements and sensor
calibration files are unavailable here. The 2026 slide deck itself is not treated as
reviewed; only its NTRS abstract is used. No protected source figures are bundled.
Case 1 shares a source group with prior development work; Case 2 groups related KSC
reports as one test family. Public-source exposure/pretraining limits blindness.

Maintain unchanged original six-case scores, source-v1 defective packet annotation
and corrected source-v2 results. New protocols must not retrospectively repair those
scores. A prospective outcome study remains future work, not a hidden acceptance gate
requiring the owner to obtain personal interviews.
