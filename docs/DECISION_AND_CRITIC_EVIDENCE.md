# How comments are grounded

A measurement's provenance and the scientific reference library answer different questions. The backend already contains independently checked accounting methods, SI constant references, selected NASA requirements and reviewed publication observations. A researcher does not need to enter those formulas or cite a NASA paper to use a calculator.

The optional **Your measurement record** field identifies the submitted experiment: for example, a lab run ID, notebook entry or measurement-file location. It does not create the scientific comparison target. An unedited validated Excel import supplies file/cell provenance automatically; this identifies the supplied record but does not authenticate its calibration. Manual inputs with no record can still produce conditional calculations; measurement trust remains unestablished. Edited imports retain their original file receipt, with manual changes distinguished.

## Backend reference classes

| Class | Purpose | Limitation |
| --- | --- | --- |
| Physical equations/constants | Charge `Q=integral I dt`, four-electron ideal O2 accounting `m=QM/(4F)`, explicit energy/geometry calculations | Ideal stoichiometry is not predicted collected oxygen or a healthy-reactor target |
| Selected official requirements | Named NASA 2026 LEIA Topic 2 profile with required/encouraged/notional categories | Applies to that demonstration context, not every reactor |
| Published measurements | Versioned Yu 2025 scalar observations with configuration, conditions and table locators | Observations from those tests, not universal ideal values or fault labels |
| User design requirements | Source-linked engineering targets and matching measurement bases | A chosen target is not automatically NASA-approved |
| Submitted experiment | Current, time, collected oxygen, energy/material/endurance records | Its actual physical truth cannot be supplied by another experiment's database row |

Primary references: [BIPM SI constants](https://www.bipm.org/en/measurement-units/si-defining-constants), [Yu et al. 2025](https://ntrs.nasa.gov/citations/20250004626), and [official NASA solicitation Attachment B2](https://sam.gov/opp/812c81b0f0b84943be12a5f29615d3c8/view). Constants and reference facts are stored/linked; free-form case conclusions are generated by Meta, not prewritten.

## Parameters are question-dependent

Current/history, electrolysis duration, collected oxygen and aligned windows support charge/output accounting. Energy performance also needs the actual energy boundary, consumption and matched oxygen window. Material interpretation needs configuration/materials, temperature/history, comparable R measurements, wall-loss/inspection method and exposure clock. Endurance needs observed run duration, outcome and matching conditions. Extraction yield needs a matching feedstock/available-oxygen inventory. Diagnostic time/budget is only needed to consider resource constraints on proposed follow-up work.

A missing field can withhold a particular interpretation without stopping all other calculations. It must not become evidence that hardware has failed. There is no universal ideal resistance, temperature, recession rate or lifetime in this reference library.

## Findings and critic comments

Every new dimension assessment and individual finding includes a short `basis` explaining why the statement follows from the cited input/calculation/reference. The separate critic call returns up to three structured comments. Each identifies its dimension, whether it challenges an inference, identifies a gap or retains the original finding, its short reason, relevant input/metric IDs and evidence IDs.

The backend rejects unknown inputs/metrics/references; numerical critic comments must cite the actual executed performance receipt. The UI displays **Why** and concise reference lines. An expandable evidence section exposes exact inputs, numerical values/formulas and the resolved source URL/locator or tool receipt. The HTML/JSON exports retain these details.

This is a separate Meta critic role/call, not an independent human expert or new experiment. Known citations and checked arithmetic do not prove that every model sentence is scientifically correct. The critic can preserve a correct original answer; changed wording is not an improvement metric. Unknown measurements, causes and failure probabilities must remain unknown.

Old saved reports remain immutable and are rendered with whichever evidence fields they originally recorded. New short reasons/comments are not fabricated retrospectively for an old result.
