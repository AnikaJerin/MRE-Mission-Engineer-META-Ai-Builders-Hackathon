# Claims allowed in the project description

Use this wording, adjusted to actual saved results:

"MRE Mission Engineer connects Meta-selected local checks, a structured claim ledger,
source-specific evidence, same-model critique and an inspectable revision into an
engineering document-review workflow. Validation references published experimental
tables and explicitly attributed findings, plus independently implemented numerical
checks. Raw model results are compared with one-pass and equal-call controls."

The project is a public-source engineering evidence MVP, not a calibrated reactor
failure predictor, autonomous controller or validated optimal-experiment planner.
Source-linked engineering reviews may be useful, but that usefulness must not be
claimed as proven from these bounded label/numeric checks alone.

State ground truth precisely: source-bounded reference labels with locators and
written bases; printed measurements versus author interpretations/projections;
separate Decimal/Fraction calculations; no privately collected raw reactor logs.
The agent's own critic, the owner's approval or model-generated explanations are
not independent experimental ground truth. Citation coverage is not semantic proof.

Report observed performance exactly, including previous checklist 6/6 versus Meta
5/6, corrected source comparison 4/4 for all methods, no added revision accuracy in
those pilots, and the omitted-temperature v1 fixture defect. Do not call that last
defect a model failure. Do not erase it after fixing the packet.

Only after the owner completes the two new live cases may the project state that
two end-to-end engineering evidence investigations were demonstrated. State the
actual claim-level unsupported endorsements, missed contradictions, numeric errors
and matched-control results. Report remaining work without a blanket "all done".

Publication: retain source citations and rights notices; no NASA endorsement or
affiliation; no bundling protected PDF/figures; no API credentials or private account
metadata in the public repository. Code and constructed review prompts are project
contributions; the underlying research is explicitly credited to its authors.
